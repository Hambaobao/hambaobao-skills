# 记忆与任务记录模板

按已有项目规则和实际任务裁剪；模板是组织内容的参考，不要求预建所有章节或空文件。索引只保存必要信息，细节放在任务记录；不得包含凭据值。

## MEMORY.md

```markdown
# <名字>

## 目录
<规则文件>、长期知识、任务材料、复用工具的路径和用途

## 必须记住
- <关键职责、偏好或约束；以不超过五条为精简目标>

## 知识索引
- <主题笔记路径> — <一句话说明>

## 进行中
- [<状态>] <任务> — <记录路径> — 下一步：<动作或等待对象>

## 最近完成
- <日期> <任务> — <记录路径>
```

开始任务、状态变化或完成时更新相应条目。保持入口简短；最近完成可只列最多五项，较旧记录可从原任务位置或已有索引查找。关键职责、约束、活动任务和恢复指针必须完整，不能为了条数或一屏长度丢失必要信息。

## 任务 record.md

```markdown
# <主题>
状态：<进行中 / 等待谁及什么 / 已完成 / 已放弃>；更新于 <日期>

## 来源与目标
<提出人、消息或任务链接、目标与范围>

## 相关
<相关任务、issue、PR 或频道>

## 当前状态与下一步
<最新状态和行动>

## 决定
- <日期> <决定> — <负责人和依据；如已取代，注明新决定>

## 产物与位置
<任务文件、工作副本、外部存储路径及交付链接>

## 验证
<做过的检查、结果及未验证范围>

## 收尾
<最终结果、遗留事项和确认可清理的范围>
```

状态与下一步保留最新情况；重要决定追加并注明取代关系，保留依据。按需链接必要证据，不在索引粘贴大段日志；保存日志前检查并脱敏。小任务可只写状态、来源和结果，去掉不适用的章节。
