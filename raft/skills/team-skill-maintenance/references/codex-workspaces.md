# Codex 工作区安装与验证

仅在目标成员已确认使用 Codex，且本次需要安装、更新或检查加载时读取。这里的路径变量都指目标成员所在电脑上的已核实路径。

## 确认搜索范围

从实际启动 Codex 的 cwd 核对 `.agents/skills` 搜索范围；在 Git 仓库内，还需检查向上至仓库根目录的技能。同名技能可能同时出现，检查返回的实际路径。

给单个 Raft 成员安装时，通常选择该成员启动目录下的 `.agents/skills/<skill-name>`。先验证这个 cwd 确实属于目标成员；多个成员共享同一操作系统用户时，用户级目录可能影响所有成员。若运行时直接从另一个项目目录启动，重新验证该 cwd 的发现结果。

同时检查相关的启用配置。存在 `.codex/config.toml` 能提供运行时线索，但仍需核对当前启动配置；配置可能来自多个作用域。

## 准备与安装

取得固定 commit 的源文件后，在临时目录审阅完整技能。复制时包括其引用的 references、scripts 和 assets，保留必要的文件权限。

如果目标环境有 `skill-installer`，读取其入口及脚本帮助后使用显式目的目录；以下是支持这些参数的安装器用法，变量由本次核验结果填写：

```bash
python3 "$installer_script" \
  --repo "$source_repo" \
  --ref "$source_commit" \
  --path "$source_skill_path" \
  --dest "$target_workspace/.agents/skills" \
  --method download
```

`installer_script` 指已找到并检查的本地安装脚本。安装器不可用时，也可从固定提交的干净检出复制完整技能目录。把包内容下载到磁盘与运行其脚本、安装额外依赖分别处理。

首次安装前检查目标路径是否存在，包括符号链接；存在时进入更新流程。普通安装工具可能拒绝已有目录，这正好可防止无意覆盖。

## 更新已有副本

1. 对照已记录的旧来源，检查完整文件集合、字节和必要的权限。本地修改或符号链接先查清；相同内容可直接保留并刷新验证记录。
2. 为获准更新保留旧目录与来源记录，将备份放到技能扫描范围以外，避免旧技能也被发现。
3. 准备并校验新目录，确认目的路径仍对应原成员和原副本后替换。采用完整目录替换，使上游删除的文件也得到清理。
4. 复查发现与启用状态；失败时修复已确定的问题或恢复旧目录，回读实际结果并报告当前使用的版本。

备份保留位置和清理时机记入维护笔记。源仓库 main 更新或 PR 合并，并不会更新已复制的成员技能。

## 检查运行时发现结果

先比较安装目录与固定来源的完整文件集合及内容；格式校验器只证明结构可解析。

优先使用目标会话现有的技能列表。需要程序化核实时，可以在与目标运行时相同的用户、配置和 cwd 下启动临时 `codex app-server`，仅进行发现查询：

```bash
codex app-server --listen stdio://
```

通过 stdin 逐行发送 JSON。收到 `initialize` 成功响应后发送 `initialized`，再请求 `skills/list`；将 `/absolute/target-workspace` 换成已核实的实际路径。

```json
{"id":1,"method":"initialize","params":{"clientInfo":{"name":"team_skill_check","version":"1.0"}}}
{"method":"initialized"}
{"id":2,"method":"skills/list","params":{"cwds":["/absolute/target-workspace"],"forceReload":true}}
```

按响应 id 读取结果，检查对应 cwd 的 `data[].skills`：技能名称和路径与预期一致、作用域符合安装范围、`enabled=true`；检查 `data[].errors`，把相关加载错误查清。为读取设定合理超时（例如 30 秒），完成后只退出本次创建的临时进程。

上述查询无需创建 thread 或启动模型 turn。临时进程的发现结果只覆盖所复现的配置；目标会话存在额外启动参数或不同 cwd 时，按实际配置继续核验。输出只保留当前技能的必要元数据。

Codex 通常自动检测技能文件变化。新技能未出现时，检查路径、禁用配置、解析错误与运行时版本；确需重启时结合任务状态和现有授权安排。实际任务中的选择与执行效果另行验证。
